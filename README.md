# 📚 Library Management System | Python

A simple, menu-driven Library Management System built with Python to manage books and practise programming through a real-world project.

## 📌 About the Project

This project is a Library Management System that allows users to perform basic library operations through a simple, interactive program.

I built this project as part of my journey of learning Python and applying the concepts I've learned to practical problems. Instead of limiting myself to small coding exercises, I wanted to build something that brings different programming concepts together in one working application.

The idea behind this project is simple: make it easier to manage a collection of books by providing options to add new books, display the collection, search for specific books, borrow and return books, and check which books are currently available.

While developing this project, I focused on understanding the logic behind each operation and how different Python concepts work together to make a program functional.

## ✨ Features

### ➕ 1. Add Books
Allows users to add books to the library collection. This feature helps maintain and expand the collection by storing information about newly added books.

### 📖 2. Display Books
Displays the books stored in the library system, making it easier to view and manage the collection.

### 📕 3. Borrow Books
Allows users to borrow books from the library. This feature represents one of the basic operations of a library system.

### 📗 4. Return Books
Allows users to return borrowed books so that they can become available for borrowing again, depending on how availability is managed in the program.

### 🔍 5. Search Books
Helps users find a particular book in the collection without having to go through every book manually.

### ✅ 6. View Available Books
Displays the books that are currently available for borrowing. This makes it easier to identify which books can be borrowed at a given time.

## 🛠️ Technologies Used

- **Python** — The primary programming language used to build the project.
- **Lists and Dictionaries** — Used for organizing and managing book information, where applicable.
- **Conditional Statements** — Used to handle different operations and user choices.
- **Loops** — Used to keep the program running so users can perform multiple operations.
- **Functions** — Used to organize the program into separate operations, making the code easier to understand and maintain.

## ⚙️ How the Program Works

The system follows a menu-driven approach that allows users to choose the operation they want to perform.

1. The program displays a menu containing the available operations.
2. The user selects an option, such as adding a book or searching for one.
3. The program performs the selected operation based on the implemented logic.
4. The result is displayed to the user.
5. The user can continue choosing different operations until they decide to exit the program.

This approach makes the program easier to navigate and provides a practical way to understand how loops, conditional statements, and functions work together.
